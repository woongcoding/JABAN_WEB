# gorebob.com · 카페24 화면·연결 개발

- `skin/`: 스킨 원본을 확인한 후 필요한 화면 변경 파일을 둔다.
- `bridges/`: 콘텐츠에서 상품·발주 화면으로 연결하는 코드를 둔다.
- 현재 운영 스킨의 사본과 실제 연결 코드는 아직 가져오지 않았다.
- API 인증·토큰·주문 수집은 기존 `JABAN_AGENT/integrations/cafe24/`에서 유지한다.
- 참조 프로토타입의 상품코드·가격·재주문을 실제 데이터로 간주하지 않는다.
- 구매 연결은 실제 상품 옵션·판매 단위·로그인·오류 상황을 검증한다.
