CHECK 03

포장 단위와 한 조각의 크기는 다릅니다

가격 비교에 앞서 주문 수량 1개의 의미와 실제 제품 조건을 확인하세요.

상품 상세에서 확인할 항목 · 실제 판매 규격은 검수 중입니다
확인 항목살펴볼 내용선택할 때 확인하세요
판매 단위·총중량팩 / 박스, 포장 총중량주문 수량 1개가 어떤 포장 단위인지 확인
개당 크기·수량개당 중량 범위, 팩당 마릿수·조각 수 표기총중량만으로 배식 수량을 확정하지 않기
손질·가시가공 형태, 가시 처리 범위와 주의사항순살 표기와 제품별 잔가시 안내를 함께 확인
염지·원산지염지 여부와 표시 내용, 해당 상품의 원산지같은 어종이어도 상품·옵션별 표시 확인
보관·배송제품 표시사항, 배송 조건과 주문 가능 상태수령 일정과 보관 조건을 구매 전 확인
왜 지금은 규격과 가격이 표시되지 않나요?

현행 판매 상품과 옵션을 대조 중입니다. 확인되지 않은 중량·가격·조각 수를 예시 상품처럼 표시하지 않으며, 검수가 끝난 상품부터 규격표와 구매 링크를 연결합니다.
