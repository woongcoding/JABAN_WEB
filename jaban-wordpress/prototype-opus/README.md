# 시안 C · 출고 라벨 (Claude Opus 제작)

컨셉 비교를 위한 jaban.co.kr 시안입니다. 다른 시안(`prototype/`, `prototype-gemini/`)과 병렬로 두고 의견을 수렴합니다. 이 폴더는 이 시안만 수정합니다.

## 컨셉 한 장 요약

| 항목 | 내용 |
|---|---|
| 컨셉명 | 출고 라벨: 수산물 박스 라벨·규격표의 시각 언어를 쓴 **안내형 + 도구형** 사이트 |
| 핵심 가설 | 방문자는 "무엇을 사야 하는지"보다 "우리 주방에 무엇이 맞는지"를 먼저 알고 싶어 한다. 고르기·계산·확인·상담 준비를 이 사이트에서 끝내면 고래밥몰 주문이 쉬워진다. |
| 첫 화면 | 고등어 중심 메시지 + "오늘 무엇을 찾으세요?" 방문 목적 4가지(급식·식당·가정·기존 구매) → 선택하면 맞춤 4단계 순서 표시 |
| 고등어 위치 | 홈 첫 문장·두 번째 영역·전용 가이드. 다른 어종은 "선택의 폭"으로 함께 표시 |
| 신뢰 표현 | 확인된 만큼만 표시. 모든 사실에 `내부 자료 기준 / 검수 대기 / 시안 예시` 상태 도장. 상단 **검수 표시 켜기**로 미확정 정보를 한눈에 확인 |
| 일부러 뺀 것 | 보증성 수치(가시 제로·수율 100% 등), 실제처럼 보이는 가짜 다운로드·접수, 생성 이미지의 실사 표기, 확인되지 않은 조리 온도·시간, 허위 사업자 정보 |

## 구현 기능 (모두 실제 동작, 서버 전송 없음)

1. **방문 목적 선택**(홈): 4개 유형별 추천 순서. 선택은 기억됨.
2. **어종·형태 찾기**(guides): 4문항 → 고등어 가공 형태 추천·이유·확인 항목, 함께 볼 어종.
3. **고등어 가공 형태 탭**(mackerel): 버터플라이·손질·순살·토막 비교, 방향키 전환.
4. **표시사항 읽는 법**(mackerel): 예시 라벨 5줄 해설.
5. **필요량 계산기**(tools): 중량 기준·개수(마리) 기준 두 방식, 산식·가정·남는 양 표시, 결과 복사.
6. **구매 전 확인표**(tools·mackerel): 14개 항목, 진행률, 남은 항목만 복사.
7. **레시피 필터**(recipes): 어종·조리·규모·검색, URL 조건(`?species=고등어&scale=대량`), 접근성 대화상자.
8. **품질 자료 요청**(quality): 자료 선택 → 상담 메모에 자동 포함.
9. **FAQ 검색**(support): 검색어 강조.
10. **상담 메모 작성기**(support): 형태 찾기·계산기·자료 요청 결과를 모아 메시지 생성 → 복사해 원하는 채널로 전달. 개인정보 입력란 없음.
11. **편의**: 글자 크게(가+), 모바일 메뉴(Esc 닫기), 모바일 하단 고정 버튼(상담 메모·고래밥몰), 본문 바로가기, 동작 줄이기 설정 존중.

저장은 이 브라우저의 `localStorage`(`jaban-c:` 접두어)만 사용합니다.

## 구조

```
prototype-opus/
├─ build.py              공통 머리말·꼬리말 + src/pages 본문 → 루트 HTML 7개 생성
├─ src/pages/*.html      페이지 본문 (첫 줄 JSON 머리말)
├─ assets/css/style.css  디자인 토큰·구성요소·반응형
├─ assets/js/data.js     콘텐츠 데이터 (어종·형태·레시피·FAQ·자료·확인표)
├─ assets/js/app.js      상호작용 (외부 라이브러리 없음)
└─ index.html 외 6개     생성 결과 — 직접 수정하지 말고 src 수정 후 build.py 실행
```

WordPress 전환 시 `data.js` 배열은 사용자 정의 글 유형으로, 머리말·꼬리말은 `header.php`/`footer.php`로 옮길 수 있습니다.

## 미리보기

```bash
cd jaban-wordpress/prototype-opus
python3 build.py
python3 -m http.server 8000   # http://localhost:8000/
```

파일을 직접 열어도 동작합니다. 웹글꼴은 Google Fonts에서 불러오며, 오프라인이면 시스템 글꼴로 대체됩니다.
