- 재현용 조회 스크립트와 민감값을 가린 결과는 Git 제외 경로 `private/wp-admin-readonly-inspector.py`, `private/wp-admin-observed.json`에 보관. 로그인 쿠키·비밀번호는 결과 파일에 저장하지 않았으며 조회 후 브라우저 세션을 종료했다. 사이트 건강의 정보 화면만 조회했으므로 전체 건강 진단·메일·백업·구매 연동 검증을 완료한 것으로 간주하지 않는다.
