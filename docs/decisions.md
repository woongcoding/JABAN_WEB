- 기존 자료는 선정한 참고 사본만 가져오고 원본은 이동하지 않는다.
- 별도 로컬 Git 저장소만 초기화한다. 원격 연결·푸시·커밋은 이번 설정에 포함하지 않는다.

## 2026-10-03 · 기술 방향

- jaban: 카페24 호스팅에서 워드프레스를 사용하는 방향.
- gorebob: 기존 카페24 쇼핑몰 유지.
- 정확한 호스팅 상품·요금·테마·게시판·외부 연동은 아직 미확정.
- 운영 사이트 배포·DNS 변경·유료 계약은 이번 로컬 프로젝트 설정에 포함되지 않는다.

## 2026-10-04 · 초안 제작 방향 확정

사용자가 권장 조합으로 진행하도록 지시했다. 급식 담당·영양사 우선, 홈의 주 행동은 제품 선택 가이드, 고등어 상세부터 검토 후 삼치·임연수·갈치 확장, 전문성과 친근함의 균형, 홈·고등어 상세·공통 메뉴 우선 제작으로 확정했다. 사실 검수 담당은 미정이며 미확인 내용은 검수 대기로 유지한다. 이번 지시는 로컬 초안 제작 범위이며 서버 적용·공개는 수행하지 않았다.

## 2026-10-06 · 최신 초안의 워드프레스 시험 구동

사용자가 최신 화면을 워드프레스에서 구동하도록 요청했다. `JABAN_project/JABAN_WEB/jaban-wordpress/prototype`의 7개 화면을 맞춤 클래식 테마와 네이티브 페이지로 전환하여 카페24 임시 주소에 적용했다. 새 플러그인 없이 표준 템플릿/훅을 사용한다. 임시 주소는 검토용으로 검색엔진 수집 억제를 적용하며 실제 공개 전 콘텐츠 검수와 해당 설정 재검토가 필요하다. `jaban.co.kr` 운영 도메인·DNS 전환은 이번 요청에 포함하지 않는다.

## 2026-10-07 · v2.2 고등어 중심 로컬 개정

고등어를 주력으로 유지하고, 삼치·임연수는 식단의 선택 폭을 넓히는 후보로 소개한다. 자료 검토 순서를 상품 노출 우선순위로 해석하지 않는다. 이번 구현은 지정된 `JABAN_project/JABAN_WEB`의 로컬 프로토타입 개정이며 공개·운영 연동은 포함하지 않는다. 미검증 상품 수치와 구매 링크는 보류하며 상담은 목적 선택과 준비 안내만 작동하는 미리보기로 제공한다.
