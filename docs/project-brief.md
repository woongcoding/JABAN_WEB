# 프로젝트 개요 · 최신 방향

## 목표

신뢰와 조리 지원을 제공하는 `jaban.co.kr`에서 고객을 유입시키고, 기존 `gorebob.com`에서 구매를 편리하게 진행하도록 한다.

## 사용자와 작업 범위

- 2026-10-07: 고등어를 홈·제품 가이드의 주력으로 유지하고, 다른 어종은 식당·급식 고객의 선택 범위를 넓히는 방향으로 소개한다.

- 주 사용자: 급식 구매 담당자·영양사, 외식업 고객, 가정용 구매 고객.
- jaban: 회사·시설 소개, 확인된 인증 자료, 어종·조리법별 콘텐츠, 유튜브, FAQ, 문의, 구매 링크.
- gorebob: 기존 카페24 구매 기능을 유지하면서 필요한 화면 개선과 상품 연결을 개발.
- 초기에는 콘텐츠를 우선 구축한다. 커뮤니티·맞춤 계산기·자동 샘플 처리·회원 통합은 별도 구현 범위를 확정한다.

## 최신 결정 및 인프라 현황

2026-10-03 카페24 매니지드 워드프레스 호스팅(`sh8945`, `sh8945.mycafe24.com`) 개설 및 관리자 로그인 검증이 완료되었습니다.
SSL(HTTPS) 적용이 완료되었으며, 현재 임시 주소 환경에서 초기 설정 및 테마/콘텐츠 구축을 진행할 수 있는 상태입니다.
기존 계획서의 정적 사이트 또는 AWS 단독 구축 권고는 참고 이력이며, 현재는 카페24 워드프레스(홍보) + 카페24 자사몰(커머스) 2-트랙 구조로 확정되었습니다.

## 구현 시 확인할 조건

- 가격·재고를 별도 수작업으로 이중 관리하지 않는다.
- 실제 상품의 판매 단위와 옵션을 확인한 뒤 계산기와 구매 연결을 만든다.
- 기존 jaban의 상품·게시글 주소를 적절한 gorebob 주소로 연결하는 이전 계획을 작성한다.
- DNS 변경 시 회사 이메일의 MX·TXT 등 기존 설정을 유지한다.
- 두 사이트의 회원 통합·장바구니 자동 담기는 별도 개발과 검증이 필요하다.
- 콘텐츠에서는 실증되지 않은 수율·조리 안전·가시 제거 보증을 사용하지 않는다.
