# 기존 자료 · 참고 사본

원본은 `JABAN_AGENT`에 유지한다. 이 폴더의 사본은 2026-10-03 시점의 참고 자료이며 최신 개발 코드는 아니다.
정확한 원본 위치와 SHA-256은 `source-manifest.json`에 기록한다.

## 계획서

`plans/`의 HTML·TXT·PDF는 기존 두 사이트 운영 계획이다.
과거의 기술 구성·커뮤니티 운영 제안은 이력으로 읽는다. 최신 기술 방향은 `../project-brief.md`의 카페24 호스팅 + 워드프레스를 따른다.

## 시연 코드

`prototypes/`의 두 HTML 파일은 검토용 시연 코드다. 실제 연동과 운영 준비가 완료된 제품이 아니다.

| 파일 | 재개발 전에 확인할 사항 |
|---|---|
| `b2b_quick_order.html` | 장바구니 연동은 알림 시연, 지난 주문은 고정값. 상품·가격·5kg 단위·사업자 표시를 실제 정보로 교체해야 함 |
| `ai_meal_planner_widget.html` | 고정 메뉴 기반 시연. 실제 AI 호출·예산 최적화·주문 수량 전달 미구현. 메뉴 횟수·계산 산식 검증 필요 |

두 파일 모두 실제 판매 단위·옵션, 모바일 화면, 조리·영양 표현을 다시 확인한다.
이 폴더를 그대로 운영 서버에 업로드하지 않는다.
