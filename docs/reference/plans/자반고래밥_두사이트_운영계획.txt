1. 운영 방향과 고객

두 사이트의 역할을 분담하고, 상품·회원·주문은 기존 카페24 쇼핑몰을 중심으로 관리한다. 회사 소개와 현장 콘텐츠를 충분히 제공하면서 구매 화면에는 상품 선택과 주문에 필요한 정보를 집중한다.

대표 행동: 제품 알아보기 · 자료 보기 · 맞춤 절단 문의 · 샘플 상담 · 해당 제품 구매

gorebob.com · 구매와 재구매

상품 검색, 규격·가공등급·판매단위 확인, 빠른 발주, 기존 주문 재사용, 결제, 주문조회, 해당 주문 서류.

우선 고객: 어린이집·유치원, 요양시설·병원·복지시설, 산업체·구내식당, 급식 식자재 유통업체.

가정용·식당용 고객: 기존 쇼핑몰 진입과 상품군을 보존하고, jaban에서 해당 구매처로 바로 연결한다. 회사 홍보 전체를 급식 한 분야로 한정하지 않는다.

기존 방침: 학교 직접 입찰 불참을 유지한다. 유통업체 경유 공급 문의는 별도 상담한다.

구매 동선: 검색·광고로 이미 제품을 정한 고객은 gorebob 상품으로 바로 연결한다. 모든 구매자에게 jaban 방문을 요구하지 않는다.

다음 단계: 저장 발주목록 → 상품코드가 들어 있는 정해진 CSV 양식 가져오기 → 식단표 해석 → 자연어 발주 초안 순으로 확장한다. 엑셀 임의 양식 전체 지원은 초기 범위에 넣지 않는다.

샘플에서 주문까지

시설 유형·관심 제품·정량·시험 사용일을 접수하고 현재 승인된 샘플 조건과 비용을 안내한다.

발송한 품목과 옵션을 기록하고, QR은 해당 제품의 사용 안내로 연결한다.

고객의 실제 사용일 이후 평가를 요청한다. 맛·규격·손질·조리 편의와 개선점을 받는다.

평가 조건에 맞춘 제품·수량·현재 견적을 제안하고 쇼핑몰 구매 또는 별도 상담으로 연결한다.

샘플·배송·응대 비용과 첫 주문, 이후 60일 재주문을 기록한다.

예전 이벤트의 무료배송·할인·제공 수량을 자동 적용하지 않는다. 참여 혜택은 피드백 제출에 대한 것으로 제공하고 긍정적 평가를 조건으로 삼지 않는다.

사이트 간 전달: jaban의 선택은 발주 초안이며 gorebob에서 판매상태·가격·단위를 재조회한 뒤 고객이 검토한다. 로그인·결제는 카페24에서 진행한다. 로그인 쿠키를 두 도메인 사이에 복사하지 않는다. 초기 jaban에 별도의 구매회원 체계를 만들지 않고, 커뮤니티 저장·알림 수요가 확인되면 인증 연계를 별도 설계한다.

구현 선택: jaban은 콘텐츠 수정이 쉬운 관리화면과 경량 웹사이트로 구성한다. 기존 자료·재주문 서비스와 연동하고 카페24의 주문·결제를 유지한다. 운영자용 로그·초안 생성부터 AI를 적용하며 고객 주문은 확인 없이 자동 제출하지 않는다.

 | 재구매·품목 확대 | 첫 구매 뒤 60일이 지난 고객의 재구매 여부·구매 어종 수 | 관찰기간을 채운 고객만 분모에 포함. 기존 고객군과 비교

 | 관계·운영 부담 | 실제 질문·사용기·반복 참여 고객, 응대시간·운영시간 | 수요가 운영 부담을 정당화할 때 회원형 커뮤니티 확대

jaban과 gorebob에 동일한 GA4 측정 기반과 교차 도메인 설정을 사용해 이동을 연결한다. 외부 유입의 캠페인 표시는 유지하고, 두 사이트 내부 이동에 임의의 캠페인 값을 덧붙여 유입 출처를 바꾸지 않는다. 쿠키 선택·차단에 따른 측정 누락은 보고서에 표시한다.  [https://support.google.com/analytics/answer/10071811?hl=ko] 공식 설정 안내

추천 이벤트: content_view / calculator_complete / product_link_click / inquiry_submit / quick_order_start / add_to_cart / purchase. 상품·콘텐츠 식별자는 기록하되 연락처·주문서 개인정보는 분석 이벤트에 넣지 않는다. purchase는 결제완료 주문과 대조해 취소·반품을 별도 반영한다.

새 홍보 사이트는 미리보기 환경에서 검토하고, 연결된 쇼핑 도메인의 단순 해제만으로 별도 홈페이지가 생긴다고 가정하지 않는다. 홍보용 호스팅과 경로별 이동을 처리할 서버 설정을 준비한 후 전환한다.

공개 전 완료조건: 주요 옛 링크·이미지 정상, 회사메일 송수신 정상, gorebob 회원로그인·기존 주문조회·재주문·장바구니 정상, 결제수단·SNS 복귀 정상, 실구매자 서류 권한 정상, 모바일 가로 넘침 없음, 측정 이벤트 확인, 복구용 DNS·운영 파일 보관.

결제 테스트는 테스트 모드 또는 별도 승인된 최소 실결제로 확인한다. 운영 고객 주문을 변경하지 않는다. 기존 상품 URL의 영구 이동은 최소 1년 이상 유지하는 안을 잡고, 단절된 상품은 대응 콘텐츠가 없으면 적절한 종료 응답을 제공한다.  [https://developers.google.com/search/docs/crawling-indexing/site-move-with-url-changes] Google 이전 안내

사업체 표기: 회사 홍보 대상인 ㈜자반과 쇼핑몰 판매주체인 자반고래밥의 관계를 실제 운영에 맞춰 설명한다. 견적·계약·증빙은 거래주체별로 관리한다.
