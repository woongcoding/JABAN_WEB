- [ ] 워드프레스·PHP 버전, 테마·플러그인 설치, SFTP/SSH 등 접근 범위 확인.

## 서비스 선택 권고

2026-10-03 공식 안내를 비교한 추천이며 상품 선택·계약은 미확정이다. jaban의 회사·품질·레시피·영상·FAQ·문의와 구매 링크 구축에는 **뉴매니지드 워드프레스 비즈니스**를 첫 후보로 권고한다. 초기 방문량과 업로드 양은 아직 측정하지 않았으므로 충분한 성능을 보장하는 판단은 아니다.

| 서비스 | 공식 안내의 특징 | 현재 프로젝트에 대한 판단 |
|---|---|---|
| [뉴매니지드 워드프레스](https://hosting.cafe24.com/?controller=new_product_page&page=managed-wordpress) | 자동 설치, SSL, 백업, 시험용 스테이징 | 콘텐츠 중심 첫 구축의 추천 |
| [애드센스 워드프레스](https://hosting.cafe24.com/?controller=new_product_page&page=adsense-wordpress) | 애드센스 연동·광고 설정·승인 지원 | 광고 수익화 기능의 우선순위가 낮아 현재는 선택 이유가 적음 |
| [워드프레스 VPS](https://hosting.cafe24.com/?controller=new_product_page&page=wordpress-vps) | 독립 자원, 캐싱·모니터링, SSH·WP-CLI, root 권한 없음 | 실제 부하·운영 요구가 공유형 범위를 넘어설 때 별도 검토 |

비즈니스의 공식 일반 월 요금은 VAT 포함 7,000원, 설치비 11,000원, SSD 4GB, 트래픽 10GB/일이다. 1년 약정 표시는 월 6,300원이며 실제 결제 조건은 신청 화면에서 확인한다. 무료 SSL, 스테이징 1개, 최대 7일 DATA/DB 자동 백업·복원이 안내되어 있다.

가격보다 먼저 확인할 운영 조건은 다음과 같다.

- 비즈니스는 일일 트래픽 소진 시 차단 조건이 있다. 영상은 유튜브 삽입 중심으로 구성하고 실제 사진·자료·유입량을 측정한다.
- 뉴매니지드와 워드프레스 VPS의 무료 스테이징은 생성 후 1개월이 지나면 자동 삭제된다. 코드·콘텐츠·자료를 별도로 보관하고 시험 환경 생성·재생성 일정을 정한다.
- 뉴매니지드는 테마·플러그인 설치를 허용하되 취약한 항목은 제한될 수 있다. 필요한 PHP 기능·외부 API 호출·접속·리디렉션은 계약 전 확인한다.
- 워드프레스 VPS는 일반 root 서버와 다르다. 별도 상주 프로그램을 자유롭게 설치할 수 있다고 가정하지 않는다.
- 기존 gorebob 쇼핑몰은 유지하고 새 jaban 시험 환경을 먼저 준비한다. 도메인 연결은 기존 메일·주소 이전 검증 후 별도 진행한다.
